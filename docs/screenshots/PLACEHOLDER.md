# Screenshots — Drop-in Instructions

Place your final PNG screenshots directly in this folder using **these exact filenames** (hyphens only, no spaces):

| Filename | Contents |
|---|---|
| `dashboard-hero.png` | Full dashboard view: AQI hero card + 24-hour hourly forecast strip |
| `ventilation-timeline.png` | 24-Hour diurnal thermal curve with Safe Ventilation Window card highlighted |
| `profile-form.png` | Profile input form showing Indian micro-location examples (e.g., Anand Vihar, Delhi) |
| `emergency-tips.png` | Emergency protocol section displayed during Severe AQI conditions |

## How to drop them in

1. Take screenshots at **1280 × 800** or **1440 × 900** resolution (or crop to that ratio).
2. Save them as PNG with the exact filenames above (lowercase, hyphens, `.png` extension).
3. Place the files in this directory: `docs/screenshots/`.
4. Remove the `> **[Screenshots pending]**` notice from the gallery section in `README.md`.
5. Commit: `git add docs/screenshots/ README.md && git commit -m "docs: add final screenshots"`.
